# iKuuu Guardian Windows 0.1.4

适配 iKuuuVPN 0.17.5 的 Windows x64 修复版本。使用 Windows UI Automation 的 InvokePattern 调用客户端控件，不移动鼠标或按坐标点击。

## 使用

1. 退出旧 Guardian，完整解压程序包。
2. 自行打开并连接 iKuuuVPN，再运行 IKuuuGuardian.exe。无需安装 .NET。
3. 右下角盾牌托盘图标可查看状态、暂停、配置、打开日志和退出。
4. 官方界面恢复需要 Windows 桌面保持解锁、远程桌面会话保持连接；首次将客户端切到“服务器”页面并展开“选择节点”，之后可以最小化。程序按控件语义识别目标，不依赖节点的屏幕位置。

默认启用官方界面模式，仅支持版本 0.17.5。恢复需要客户端保留在服务器页面；支持保持最小化，不展开窗口、不移动鼠标、不抢占鼠标操作。可以继续操作其他软件；恢复期间请避免手动修改 iKuuu 节点或页面。若手动修改节点或系统代理路径变化，程序停止本次恢复。其他客户端版本应关闭官方界面模式，使用已验证的本机 Controller 接口或仅检测。

## 最近事件

右键盾牌托盘图标，在“最近事件”下查看最近 3 条记录，最新在上方，显示相对时间和事件摘要。连续重复状态不会刷新记录。异常确认、测速、切换结果、失败回退、开启/暂停等状态都会记录。双击盾牌的详细状态也显示完整事件文字。

记录保存在 `%LOCALAPPDATA%\IKuuuGuardian\recent-events.json`，重启后保留。记录可能含节点名称，分享前请检查；不会自动上传。

## 本次修复

0.1.4 为 exe 嵌入与托盘一致的绿色盾牌图标，包含 16–256 像素的多尺寸图标。

0.1.3 新增与 Mac 版一致的最近 3 条事件展示。0.1.2 已移除恢复时展开窗口的操作，后台调用节点控件，支持保持最小化。已在最小化状态实测完整测速、切换、真实网络复检和失败回退；每次操作均确认窗口保持最小化。

- 原探针请求 ChatGPT 页面可能返回 Cloudflare 浏览器验证 403，造成可达线路被判失败。改用未登录 OpenAI API 加公共网络探针；401 表示 API 入口可达，不表示已登录。
- Controller 延迟检测改用 gstatic 的 204 地址。
- 新增官方节点列表适配、测速和选择，排除台湾节点。官方延迟全部超时时，最多逐个验证三个允许节点。
- 切换后复查实际选择和网络；候选均失败时尝试回退原节点。不会回退至排除地区，也不覆盖已观察到的手动选择。
- 探针强制新连接，避免切换后复用旧节点连接。
- 测速刷新后重新识别目标控件，避免旧控件失效与同名分组歧义。
- 日志记录 HTTP 状态、代理路径和恢复错误原因。

检测每轮完成后间隔 5 秒，连续失败至少 20 秒后再确认。每个 HTTP 探针最多 6 秒，恢复耗时还包括官方测速、切换及复检。成功冷却 120 秒，失败重试间隔 30 秒。暂停或退出取消操作，必要时给予回退最多 20 秒。

探针为 https://api.openai.com/v1/models 、https://www.gstatic.com/generate_204 、https://www.cloudflare.com/cdn-cgi/trace 。OpenAI 接受 2xx/401/404/405，公共探针接受 2xx；403/429/5xx 不判健康。不读取登录令牌、订阅或聊天内容，不能保证 ChatGPT 登录、Codex 会话、账户权限或流式请求可用。

## 配置与日志

系统代理支持本机 HTTP/SOCKS5，未设置代理时使用系统路由；PAC 暂不支持。程序不修改系统代理，不启动 VPN、不安装服务或设置开机自启。

日志与配置在 `%LOCALAPPDATA%\IKuuuGuardian`。配置在托盘“配置自动切换”保存后立即生效。日志可能包含节点名称，分享前请检查。

可选 Controller 模式需要客户端确实提供 Clash/Mihomo 的回环接口。验证接口并选择实际承载流量的手动策略组后启用；启用时优先使用 Controller。密钥由当前用户 DPAPI 加密，不写进日志。此机官方客户端没有可用 Controller，不能将代理端口 7890 当作管理接口。

## 验证与构建

2026-10-12 本机验收：46 项回归检查通过（包括事件排序、去重、恢复和时间显示）；实际系统代理 127.0.0.1:7890 返回 API 401、公共探针 204/200。官方测速返回 36 个成功延迟。已实测加拿大→指定美国节点→实际网络复检→恢复加拿大；完整恢复流程及模拟候选验证失败后的真实自动回退均通过。模拟故障只用于触发测试流程，切换、测速、回退和成功后的网络验证均使用真实客户端。

开发者需要 .NET 10 SDK：

```powershell
dotnet run --project Windows/Guardian.Tests/Guardian.Tests.csproj -- --live-probe
dotnet publish Windows/Guardian.Windows/Guardian.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

退出后删除解压目录即可卸载；专用日志配置目录可按需删除。原软件包未覆盖。

UI Automation 不提供原子比较并切换，最后一次核对与控件接受操作之间仍有极短竞争窗口。恢复操作期间请避免手动修改 iKuuu 节点。
