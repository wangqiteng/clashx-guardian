# ClashX Guardian v2.4.0 零配置双客户端设计

## 目标

ClashX Guardian 在不主动启动代理软件的前提下，自动识别已经运行的 ClashX Pro 或 iKuuuVPN。普通用户安装并开启 Guardian 后无需填写端口、密钥或策略组；网络故障时自动测速、选择低延迟节点并验证 Codex 连通性。

## 明确边界

- 两个代理客户端都未运行时，Guardian 保持等待，不启动任何代理软件。
- ClashX Pro 与 iKuuuVPN 同时运行时，只使用 ClashX Pro。
- ClashX Pro 使用本地 Controller API；iKuuuVPN 使用 macOS 辅助功能接口。
- iKuuuVPN 没有稳定公开的节点控制 API，因此不修改其配置、不读取订阅、不调用私有网络接口。
- 辅助功能操作不移动鼠标、不发送键盘输入、不依赖绝对屏幕坐标，也不主动将 iKuuuVPN 窗口置前。

## 架构

### 后台 Guardian

Perl 后台进程继续负责低资源网络探测、失败计时、冷却和切换后连通性验证。它增加客户端自动识别与切换协调：

1. 检测 ClashX Pro 是否正在运行且 Controller 可用。
2. ClashX 不可用时检测 iKuuuVPN 是否正在运行。
3. ClashX 继续走现有 Controller 测速与切换流程。
4. iKuuuVPN 模式下向菜单栏应用写入一次性切换请求，并等待有超时边界的结果文件。
5. 菜单栏应用返回候选节点后，Guardian 逐个请求选择并执行 Codex/公共外网复检。

后台与菜单栏应用只通过 `~/Library/Application Support/ClashXGuardian/` 下的原子 JSON 文件通信。请求包含随机 ID、操作类型、超时时间和候选序号；响应包含状态、脱敏错误原因、节点显示名与延迟，不包含账户、订阅或密钥。

### 代理客户端适配层

统一能力包括：客户端是否运行、是否可自动切换、当前节点、发起测速、列出候选、选择节点、确认选择和恢复原节点。

- ClashX 适配器位于后台进程，使用 Controller API。
- iKuuuVPN 适配器位于原生菜单栏应用，使用 `AXUIElement`。
- 自动识别结果写入状态文件，菜单显示当前客户端和切换能力。

## 零配置发现

默认配置使用以下自动值：

- `PROXY_CLIENT=auto`
- `PROXY_URL=auto`
- `CONTROLLER_URL=auto`
- `PROXY_GROUP=auto`

ClashX 自动模式读取当前 macOS 系统代理地址、ClashX 用户偏好中的 Controller 端口与密钥，并从 Controller 返回的数据中识别主要 Selector。只有多个 Selector 同样可信且无法判断时才要求用户选择。显式配置继续作为高级覆盖项。

iKuuuVPN 不增加用户配置项。通过 bundle identifier `org.ikuuu.vpn` 判断是否运行，通过其标准辅助功能树读取服务器页、当前节点、节点卡片和延迟。

## iKuuuVPN 授权体验

只有 ClashX 未运行且 iKuuuVPN 正在运行时，菜单栏应用才检查辅助功能权限。

- 未授权时弹出一次说明窗口，提供“打开系统设置”和“稍后”操作。
- 用户选择稍后后不重复打扰；菜单保留“授权 iKuuu 自动保护”。
- 未授权期间继续监测，状态为“等待授权”，不尝试切换。
- 授权变化无需重装或重启 Guardian，菜单栏应用定期低频重新检查。

临时签名安装包升级后，macOS 可能要求重新授权。正式 Developer ID 签名可改善权限延续，但不作为 v2.4.0 的功能前置条件。

## iKuuuVPN 测速与切换

当前验证目标为 iKuuuVPN 0.17.5。辅助功能树已确认暴露服务器窗口、选择节点区域、节点按钮、节点名称、毫秒延迟和“超时”状态。

1. 查找 iKuuuVPN 进程和标准窗口，不启动或激活应用。
2. 确认窗口包含“服务器”和“选择节点”语义区域。
3. 通过辅助功能角色、层级和窗口内相对位置识别刷新按钮，不使用屏幕绝对坐标。
4. 执行 `AXPress` 后等待节点结果进入更新状态并稳定；总等待有固定上限。
5. 解析节点按钮：只接受以正整数毫秒结尾的结果，排除“超时”、缺失延迟和特殊路由。
6. 按本次延迟升序返回候选，最多尝试配置允许的数量。
7. 对目标节点执行 `AXPress`，重新读取顶部当前节点确认选择成功。
8. Guardian 进行真实 Codex 与公共外网探测；失败则尝试下一候选。
9. 所有候选失败时请求恢复原节点，并确认恢复结果。

## 安全保护

- 每次请求使用唯一 ID；过期响应和重复请求被忽略。
- 同一时刻只允许一个 iKuuu 操作，故障冷却沿用现有策略。
- 至少识别两个合法节点后才允许操作。
- 切换前后都必须读取并确认节点名称。
- 辅助功能结构、窗口、按钮或结果发生歧义时立即停止，不进行猜测点击。
- 结构不兼容时状态显示“当前 iKuuu 版本暂不兼容”，Guardian 继续做网络监测。
- 日志不得记录账户、订阅 URL、控制密钥或 iKuuu 私有接口内容。

## 菜单栏体验

菜单增加：

- 当前客户端：ClashX Pro、iKuuuVPN 或未检测到。
- 自动切换：可用、等待授权、版本不兼容或客户端未运行。
- 当前节点、最近测速时间、最近切换结果。
- 按状态显示“授权 iKuuu 自动保护”或“重新检查权限”。
- “立即检测”和“立即测速并恢复”。

彩色盾牌含义保持一致：绿色为连接健康；黄色为检测、授权或切换中；红色为确认故障或恢复失败；灰色为 Guardian 停止或没有已运行的代理客户端。
